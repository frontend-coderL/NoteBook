## 1、创建Vue项目

方式一：Vue CLI

- 基于webpack工具；
- 命令：vue create

方式二：create-vue

- 基于vite工具；
- 命令：npm init vue@latest

项目配置:

- 配置项目的icon
- 配置项目的标题
- 配置jsconfig.json

## 3、CSS样式的重置

对默认CSS样式进行重置:

- normalize.css   `npm install normalize.css --save`

```js
import "normalize.css"
```

- reset.css

```css
body, h1, h2, h3, h4, ul, li {
  padding: 0;
  margin: 0;
}

ul, li {
  list-style: none;
}

a {
  text-decoration: none;
  color: #333;
}

img {
  vertical-align: top;
}
```
