### 一、媒体查询：移动优先

以移动端为基准，逐步增强到 PC：

```css
/* 默认：移动端 */
section { font-size: 20px; }

/* 平板及以上 */
@media screen and (min-width: 640px) {
  section { font-size: 16px; }
}

/* PC 及以上 */
@media screen and (min-width: 768px) {
  section { font-size: 25px; }
}
```

### 二、移动端适配：rem vs viewport

场景：固定 px 字体在不同尺寸手机上显示效果不一致。

#### rem 适配

1rem = html 根标签的 fontSize，根据屏幕宽度动态计算：

```javascript
const MAX_FONT_SIZE = 42;

document.addEventListener('DOMContentLoaded', () => {
  const html = document.querySelector('html');
  let fontSize = window.innerWidth / 10;
  fontSize = fontSize > MAX_FONT_SIZE ? MAX_FONT_SIZE : fontSize;
  html.style.fontSize = fontSize + 'px';
});
```

#### viewport 适配

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
```

样式中用 `vw`/`vh` 代替 `px`。

#### 小结

rem 和 viewport 都能根据屏幕大小自动调整尺寸单位。企业移动端开发推荐 viewport。

### 三、移动端异形屏适配

刘海屏、底部横条等遮挡区域需要安全区适配：

```html
<!-- 1. 设置 viewport-fit=cover -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover">
```

```css
/* 2. 使用 constant/env 设置安全区域 */
.safe-area-bottom {
  position: fixed;
  bottom: constant(safe-area-inset-bottom); /* iOS < 11.2 */
  bottom: env(safe-area-inset-bottom);      /* iOS >= 11.2 */
  width: 100%;
  height: 46px;
}
```

四个方向的安全区变量：

- `safe-area-inset-left`
- `safe-area-inset-right`
- `safe-area-inset-top`
- `safe-area-inset-bottom`

### 四、TailwindCSS 响应式架构

后台系统可直接用组件库（如 Element Plus），但前台系统面向用户，需要高定制化、高个性化、高交互性，组件库无法满足。

TailwindCSS 解决 CSS 开发痛点：

- 变量多难维护
- 类名命名困难
- HTML 和 CSS 来回翻看
- 响应式需要大量 CSS

#### 集成到 Vite 项目

```bash
npm install -D tailwindcss postcss autoprefixer scss
```

`src/styles/index.scss`（在 main.js 中导入）：

```scss
@tailwind base;
@tailwind components;
@tailwind utilities;
```

`tailwind.config.js`：

```javascript
export default {
  content: ['./index.html', './src/**/*.{vue,js}'],
  theme: { extend: {} },
  plugins: [],
}
```

`postcss.config.js`：

```javascript
export default {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
}
```

### 五、企业级 Vite 配置

PC 和移动端的路由结构差异：

- 移动端：整页跳转，不需要路由嵌套，一个路由出口即可。
- PC 端：固定区域为一级路由（如 header），切换区域为二级路由。

#### 判断当前设备（PC / 移动端）

`src/constants/index.js`：

```javascript
export const PC_DEVICE_WIDTH = 1280
```

`src/utils/flexible.js`：

```javascript
import { computed } from 'vue'
import { useWindowSize } from '@vueuse/core'
import { PC_DEVICE_WIDTH } from '@/constants'

const { width } = useWindowSize()

// 用 vueuse 的 useWindowSize 获取响应式宽高
// 避免 document.documentElement.clientWidth 非响应式导致 computed 不更新
export const isMobileTerminal = computed(() => {
  return width.value < PC_DEVICE_WIDTH
})
```

注意：直接用 `document.documentElement.clientWidth` 做 computed 依赖不可靠（非响应式数据），需用 `@vueuse/core` 的 `useWindowSize` 获取响应式宽高。

#### Axios 配置

`src/utils/request.js`：

```javascript
import axios from 'axios'

const service = axios.create({
  baseURL: import.meta.env.VITE_BASE_API,
  timeout: 5000
})

service.interceptors.request.use(
  (config) => config,
  (error) => Promise.reject(error)
)

service.interceptors.response.use(
  (response) => {
    const { success, message, data } = response.data
    if (success) return data
    return Promise.reject(new Error(message))
  },
  (error) => {
    if (error.response?.data?.code === 401) {
      // token 超时处理
    }
    return Promise.reject(error)
  }
)

export default service
```

#### 动态路由表

`src/router/index.js`：

```javascript
import { createRouter, createWebHistory } from 'vue-router'
import { isMobileTerminal } from '@/utils/flexible'
import mobileRoutes from './modules/phone-router'
import pcRoutes from './modules/pc-router'

const router = createRouter({
  history: createWebHistory(),
  routes: isMobileTerminal.value ? mobileRoutes : pcRoutes
})

export default router
```

#### 动态 rem（TailwindCSS 适配）

`src/utils/flexible.js`（在 main.js 中调用）：

```javascript
export const useREM = () => {
  const MAX_FONT_SIZE = 40
  document.addEventListener('DOMContentLoaded', () => {
    const html = document.querySelector('html')
    let fontSize = window.innerWidth / 10
    fontSize = fontSize > MAX_FONT_SIZE ? MAX_FONT_SIZE : fontSize
    html.style.fontSize = fontSize + 'px'
  })
}
```

TailwindCSS 默认最小字体 0.75rem，在动态 rem 下会过大，需要覆盖：

`tailwind.config.js`：

```javascript
export default {
  content: ['./index.html', './src/**/*.{vue,js}'],
  theme: {
    extend: {
      fontSize: {
        xs: ['0.25rem', '0.35rem'],
        sm: ['0.35rem', '0.45rem'],
        base: ['0.45rem', '0.55rem'],
        lg: ['0.55rem', '0.65rem'],
        xl: ['0.65rem', '0.75rem']
      }
    }
  },
  plugins: [],
}
```
