图片是现代 Web 应用里最重的资源。JS 调优收益有限，图片优化才是 ROI 最高的性能环节。

### 五层优化体系

```
1. 懒加载（IntersectionObserver）
    ↓
2. 动态选择（DPR + 网络状况）
    ↓
3. 解码优先级（async decoding）
    ↓
4. 客户端压缩（Canvas / Web Worker）
    ↓
5. Cache API 手动缓存
```

### 第一层：懒加载（IntersectionObserver）

原生 `loading="lazy"` 不受控制，浏览器决定何时加载。用 IntersectionObserver 可以提前 200-500px 触发加载：

```javascript
const lazyObserver = new IntersectionObserver(
  (entries) => {
    entries.forEach(entry => {
      if (!entry.isIntersecting) return;
      const img = entry.target;
      img.src = img.dataset.src;
      img.onload = () => {
        img.classList.add('loaded');
        lazyObserver.unobserve(img);
      };
    });
  },
  { rootMargin: '200px 0px' } // 提前 200px 触发
);

document.querySelectorAll('img[data-src]').forEach(img => {
  lazyObserver.observe(img);
});
```

降级策略：

```javascript
if ('IntersectionObserver' in window) {
  lazyObserver.observe(img);
} else {
  img.loading = 'lazy';
  img.src = img.dataset.src;
}
```

效果：商品列表页首屏图片请求从 50 张降到 12 张，首屏渲染时间砍半。

### 第二层：根据设备和网络动态选择图片

计算最优图片宽度（考虑 DPR）：

```javascript
function calculateOptimalImageWidth() {
  const dpr = window.devicePixelRatio || 1;
  const viewportWidth = Math.min(window.innerWidth, 1920);
  return Math.ceil(viewportWidth * dpr);
}
```

根据网络状况调整质量（Network Information API）：

```javascript
function getImageQuality() {
  const connection = navigator.connection ||
    navigator.mozConnection ||
    navigator.webkitConnection;

  if (!connection) return 80;

  // 省流模式
  if (connection.saveData) return 40;

  const qualityMap = {
    'slow-2g': 30,
    '2g': 30,
    '3g': 60,
    '4g': 80,
    '5g': 90
  };
  return qualityMap[connection.effectiveType] || 80;
}
```

完整加载策略：

```javascript
function loadSmartImage(imageElement) {
  const width = calculateOptimalImageWidth();
  const quality = getImageQuality();

  const imageUrl = new URL(imageElement.dataset.src);
  imageUrl.searchParams.set('w', width);
  imageUrl.searchParams.set('q', quality);
  imageElement.src = imageUrl.toString();
}
```

效果：图片流量消耗降低 35%。

### 第三层：解码优先级

下载和解码是两回事：500KB JPEG 下载 200ms，解码可能要 800ms。

```javascript
// 首屏关键图片：同步解码 + 高优先级
const heroImage = document.querySelector('.hero');
heroImage.decoding = 'sync';
heroImage.fetchPriority = 'high';

// 非关键图片：异步解码，不阻塞主线程
const thumbnails = document.querySelectorAll('.thumbnail');
thumbnails.forEach(img => {
  img.decoding = 'async';
  img.fetchPriority = 'low';
});
```

预加载获取尺寸，避免 CLS：

```javascript
async function preloadImageWithDimensions(src) {
  return new Promise((resolve, reject) => {
    const img = new Image();
    img.onload = () => {
      resolve({
        element: img,
        width: img.naturalWidth,
        height: img.naturalHeight,
        aspectRatio: img.naturalWidth / img.naturalHeight
      });
    };
    img.onerror = reject;
    img.src = src;
  });
}

// 提前设置宽高比，避免布局偏移
const imageData = await preloadImageWithDimensions('/photo.jpg');
container.style.aspectRatio = imageData.aspectRatio;
container.appendChild(imageData.element);
```

### 第四层：客户端压缩

用 Canvas API + OffscreenCanvas 在上传前压缩：

```javascript
async function compressImageOnClient(file, maxWidth = 1920) {
  const bitmap = await createImageBitmap(file);
  const scale = Math.min(1, maxWidth / bitmap.width);
  const newWidth = Math.floor(bitmap.width * scale);
  const newHeight = Math.floor(bitmap.height * scale);

  const canvas = new OffscreenCanvas(newWidth, newHeight);
  const ctx = canvas.getContext('2d');
  ctx.drawImage(bitmap, 0, 0, newWidth, newHeight);

  return await canvas.convertToBlob({
    type: 'image/webp',
    quality: 0.8
  });
}
```

实测：iPhone 照片 8.3MB → 0.6MB，压缩率 92.8%。

Web Worker 处理多张图片（不阻塞主线程）：

```javascript
// imageCompressor.worker.js
self.addEventListener('message', async (e) => {
  const { file, maxWidth } = e.data;
  const bitmap = await createImageBitmap(file);
  const scale = Math.min(1, maxWidth / bitmap.width);

  const canvas = new OffscreenCanvas(
    Math.floor(bitmap.width * scale),
    Math.floor(bitmap.height * scale)
  );
  const ctx = canvas.getContext('2d');
  ctx.drawImage(bitmap, 0, 0, canvas.width, canvas.height);

  const blob = await canvas.convertToBlob({ type: 'image/webp', quality: 0.8 });
  self.postMessage({ blob, originalSize: file.size });
});

// 主线程
```

### 第五层：Cache API 手动缓存

HTTP 缓存由服务端控制，隐私模式下失效。用 Cache API 手动管理：

```javascript
const IMAGE_CACHE_NAME = 'image-cache-v1';

async function cacheImage(url) {
  const cache = await caches.open(IMAGE_CACHE_NAME);
  const cached = await cache.match(url);
  if (cached) return cached;

  const response = await fetch(url);
  if (response.ok) {
    await cache.put(url, response.clone());
  }
  return response;
}

async function loadImageWithCache(imgElement) {
  const url = imgElement.dataset.src;
  const response = await cacheImage(url);
  const blob = await response.blob();
  imgElement.src = URL.createObjectURL(blob);
}
```

缓存清理（控制大小）：

```javascript
async function cleanOldCache(maxSize = 50 * 1024 * 1024) {
  const cache = await caches.open(IMAGE_CACHE_NAME);
  const requests = await cache.keys();
  let totalSize = 0;
  const items = [];

  for (const request of requests) {
    const response = await cache.match(request);
    const blob = await response.blob();
    items.push({ request, size: blob.size });
    totalSize += blob.size;
  }

  if (totalSize > maxSize) {
    for (const item of items) {
      if (totalSize <= maxSize) break;
      await cache.delete(item.request);
      totalSize -= item.size;
    }
  }
}

setInterval(cleanOldCache, 5 * 60 * 1000);
```

效果：二次访问加载从 800ms 降到 50ms，离线可用，流量降低 70%。

### 核心思路

浏览器只关心四件事：字节数、解码时间、布局稳定性、渲染时机。图片优化的每一行代码都应服务于这四个目标。

性能不是锦上添花，性能本身就是功能。
