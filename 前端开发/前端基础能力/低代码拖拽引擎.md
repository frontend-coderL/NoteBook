低代码编辑器核心只有两个部分：

- DSL（JSON Schema）：用 JSON 描述页面结构
- 拖拽引擎（Drag Engine）：修改这个 JSON

本文基于 Vue 3 原生实现，不依赖 vuedraggable 等第三方库。

### DSL 设计

树形结构，拖拽 = 修改数组（移动 / 插入元素）：

```javascript
const schema = ref([
  {
    id: '1',
    type: 'Container', // 容器组件，可嵌套
    children: [
      { id: '2', type: 'Button', label: '提交' },
      { id: '3', type: 'Input', placeholder: '请输入' }
    ]
  },
  { id: '4', type: 'Text', content: '我是文本' }
]);
```

### 渲染引擎：递归组件

```vue
<!-- Renderer.vue -->
<script setup>
const props = defineProps(['schema']);
</script>

<template>
  <div class="canvas-area">
    <component
      v-for="node in schema"
      :key="node.id"
      :is="node.type"
      v-bind="node"
    >
      <!-- 核心：有 children 就递归渲染自己 -->
      <Renderer v-if="node.children" :schema="node.children" />
    </component>
  </div>
</template>
```

### 拖拽引擎：HTML5 Drag & Drop 三剑客

#### 1. DragStart（物料区拖出组件）

```javascript
const handleDragStart = (e, type) => {
  e.dataTransfer.setData('type', type);
  e.dataTransfer.effectAllowed = 'copy';
};
```

#### 2. DragOver（计算插入位置 — 难点）

核心算法：获取鼠标下的 DOM 元素，判断插在前面还是后面。

```javascript
const handleDragOver = (e) => {
  e.preventDefault(); // 必须阻止，否则不能 Drop

  const target = e.target.closest('.component-item');
  if (!target) return;

  const rect = target.getBoundingClientRect();
  const midY = rect.top + rect.height / 2;

  // 鼠标在元素上半部分 → 插入到前面
  // 鼠标在元素下半部分 → 插入到后面
  if (e.clientY < midY) {
    showPlaceholder('top', target);
  } else {
    showPlaceholder('bottom', target);
  }
};
```

#### 3. Drop（修改 JSON 数据）

```javascript
const handleDrop = (e) => {
  const type = e.dataTransfer.getData('type');

  // 根据 DragOver 计算出的索引，splice 进数组
  schema.value.splice(targetIndex, 0, {
    id: generateUUID(),
    type: type,
    ...defaultProps[type]
  });
};
```

### 占位指示器（蓝色横条）

不要在 DOM 里真的插入 div（会导致页面抖动），而是用 fixed 定位的 div，根据 DragOver 计算的坐标动态改变位置。

```javascript
const updatePlaceholder = (rect, position) => {
  placeholder.style.display = 'block';
  placeholder.style.width = rect.width + 'px';
  placeholder.style.left = rect.left + 'px';

  if (position === 'top') {
    placeholder.style.top = rect.top + 'px';
  } else {
    placeholder.style.top = rect.bottom + 'px';
  }
};
```

### Iframe 隔离（进阶）

画布区用 Iframe 隔离，防止编辑器 CSS 污染画布样式：

- 编辑器 → Iframe：`postMessage` 发送 JSON Schema，Iframe 内部渲染
- Iframe → 编辑器：Iframe 内部监听 dragover，算出坐标，发消息给编辑器显示蓝色占位线

### 核心知识点

低代码编辑器考验三项前端能力：

- 递归组件（JSON Schema → 视图）
- DOM 几何计算（拖拽位置判断）
- 数据驱动视图（修改 JSON = 修改界面）
