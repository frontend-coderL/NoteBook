# 错误监控

亮点：
- 五层错误捕获：同步 JS、Promise、资源加载、Vue/React 框架层、接口层，全覆盖
- 错误去重与聚合：1 分钟窗口内相同错误只上报一次，避免刷屏
- 双通道上报：`fetch` 常规上报 + `navigator.sendBeacon` 页面关闭兜底
- Source Map 还原：Vite 构建配置 + Sentry CLI 上传，线上报错精确定位源码行
- Sentry 集成：错误聚合、趋势图、告警通知一站式，`@sentry/vue` 开箱即用

## 监控的错误类型

| 类型 | 说明 | 捕获方式 |
|---|---|---|
| 同步 JS 错误 | `throw new Error()`、`undefined.x` | `window.onerror` |
| 异步错误 | Promise reject 未 catch | `unhandledrejection` |
| 资源加载错误 | 图片、脚本 404 | `window.addEventListener('error', ..., true)` |
| 框架错误 | Vue/React 组件内错误 | `errorHandler` / Error Boundary |
| 接口错误 | 4xx、5xx | 封装 axios/fetch 统一处理 |

## 基础错误捕获

### window.onerror — 同步错误

```TypeScript
// src/utils/errorMonitor.ts

window.onerror = function (
  message: string,
  source?: string,
  lineno?: number,
  colno?: number,
  error?: Error
) {
  const errorInfo = {
    type: 'js',
    message,
    source,
    lineno,
    colno,
    stack: error?.stack,
    userAgent: navigator.userAgent,
    url: window.location.href,
    timestamp: Date.now()
  }
  reportError(errorInfo)
  return false  // 不阻止默认控制台输出
}
```

### unhandledrejection — Promise 错误

```TypeScript
window.addEventListener('unhandledrejection', (event) => {
  const error = event.reason
  const errorInfo = {
    type: 'promise',
    message: error?.message || String(error),
    stack: error?.stack,
    url: window.location.href,
    timestamp: Date.now()
  }
  reportError(errorInfo)
  event.preventDefault()  // 阻止控制台默认输出
})
```

### 资源加载错误

```TypeScript
window.addEventListener('error', (event) => {
  // 区分资源加载错误（无 lineno）和 JS 错误
  if (event.target !== window) {
    const target = event.target as HTMLElement
    reportError({
      type: 'resource',
      tagName: target.tagName,
      src: (target as HTMLImageElement).src || (target as HTMLScriptElement).src,
      url: window.location.href,
      timestamp: Date.now()
    })
  }
}, true)  // 捕获阶段
```

## 框架层错误捕获

### Vue 3 全局错误处理

```TypeScript
// main.ts
import { createApp } from 'vue'
import App from './App.vue'

const app = createApp(App)

app.config.errorHandler = (err, instance, info) => {
  reportError({
    type: 'vue',
    message: err?.message,
    stack: err?.stack,
    componentName: instance?.$options?.name,
    lifecycleHook: info,
    url: window.location.href,
    timestamp: Date.now()
  })
}

app.mount('#app')
```

### React Error Boundary

```TypeScript
// ErrorBoundary.tsx
import { Component, ErrorInfo, ReactNode } from 'react'

interface Props {
  children: ReactNode
  fallback?: ReactNode
}

interface State {
  hasError: boolean
  error?: Error
}

export class ErrorBoundary extends Component<Props, State> {
  state: State = { hasError: false }

  static getDerivedStateFromError(error: Error): State {
    return { hasError: true, error }
  }

  componentDidCatch(error: Error, errorInfo: ErrorInfo) {
    reportError({
      type: 'react',
      message: error.message,
      stack: error.stack,
      componentStack: errorInfo.componentStack,
      url: window.location.href,
      timestamp: Date.now()
    })
  }

  render() {
    if (this.state.hasError && this.props.fallback) {
      return this.props.fallback
    }
    if (this.state.hasError) {
      return <div>页面出错了，请刷新重试</div>
    }
    return this.props.children
  }
}
```

## 上报与聚合

### 上报函数

```TypeScript
function reportError(payload: Record<string, unknown>) {
  // 开发环境仅打印
  if (import.meta.env.DEV) {
    console.error('[ErrorMonitor]', payload)
    return
  }

  const body = JSON.stringify(payload)

  // 方案 1：自有接口
  fetch('/api/monitor/error', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body
  }).catch(() => {})

  // 方案 2：页面关闭时更可靠
  navigator.sendBeacon('/api/monitor/error', body)
}
```

### 错误去重与聚合

```TypeScript
const errorCache = new Map<string, number>()
const AGGREGATE_WINDOW = 60000  // 1 分钟内相同错误只上报一次

function getErrorKey(payload: Record<string, unknown>): string {
  return `${payload.message}-${payload.source}-${payload.lineno}-${payload.colno}`
}

function reportError(payload: Record<string, unknown>) {
  const key = getErrorKey(payload)
  const last = errorCache.get(key)
  if (last && Date.now() - last < AGGREGATE_WINDOW) {
    return  // 跳过重复
  }
  errorCache.set(key, Date.now())
  // ... 实际上报逻辑
}
```

### Sentry 接入

```Shell
npm install @sentry/vue  # React 项目用 @sentry/react
```

```TypeScript
// main.ts
import * as Sentry from '@sentry/vue'

Sentry.init({
  app,
  dsn: 'https://xxx@xxx.ingest.sentry.io/xxx',
  environment: import.meta.env.MODE,
  tracesSampleRate: 0.2,
  beforeSend(event) {
    // 过滤敏感信息、忽略特定错误
    if (event.message?.includes('ResizeObserver')) return null
    return event
  }
})
```

```Shell
# 构建后上传 Source Map
npx @sentry/cli sourcemaps upload --org=xxx --project=xxx ./dist
```
