技术栈：Vue3 + Canvas + TensorFlow\.js（MediaPipe FaceDetector）

适用场景：身份核验、人脸打卡、自定义拍照。

### 核心需求

- 基础拍照，前置摄像头
- 拍照自动叠加 Logo + 时间戳水印
- 实时人脸框选
- 全机型 + 微信浏览器适配

### 调用原生相机 API

```vue
<script setup>
import { ref } from 'vue';

const videoRef = ref(null);
const isCameraActive = ref(false);
let stream = null;

async function initCamera() {
  stream = await navigator.mediaDevices.getUserMedia({
    video: {
      facingMode: 'user',  // 前置摄像头
      width: { ideal: 1080, max: 1920, min: 640 },
      height: { ideal: 1920, max: 1080, min: 480 }
    },
    audio: false
  });
  videoRef.value.srcObject = stream;
  await videoRef.value.play();
  isCameraActive.value = true;
}
</script>

<template>
  <video ref="videoRef" playsinline muted></video>
</template>
```

`playsinline` 必须加，否则 iOS 微信会强制全屏播放。

### Canvas 自定义水印

原生 API 无法直接加水印，用 Canvas 承载视频帧，绘制后输出图片：

```javascript
const canvasRef = ref(null);

function takePhoto() {
  const ctx = canvasRef.value.getContext('2d');
  ctx.drawImage(videoRef.value, 0, 0, canvasRef.value.width, canvasRef.value.height);

  // 文字水印 + 时间戳
  ctx.fillStyle = 'rgba(255, 255, 255, 0.7)';
  ctx.font = '16px Arial';
  ctx.fillText(`© 公司名称 ${new Date().toLocaleString()}`, 20, canvasRef.value.height - 20);

  return canvasRef.value.toDataURL('image/png');
}
```

图片水印用 `ctx.drawImage` 绘制 Logo 即可。

### 实时人脸框选（TensorFlow\.js）

依赖 `@tensorflow-models/face-landmarks-detection`，MediaPipe 模型低延迟：

```javascript
import * as faceLandmarksDetection from '@tensorflow-models/face-landmarks-detection';

let faceDetector = null;
let detectionInterval = null;

async function initFaceDetection() {
  faceDetector = await faceLandmarksDetection.createDetector(
    faceLandmarksDetection.SupportedModels.MediaPipeFaceDetector,
    { runtime: 'mediapipe', modelType: 'short' }
  );
  detectionInterval = setInterval(detectFaces, 100);  // 每 100ms 检测
}

async function detectFaces() {
  if (!faceDetector || !isCameraActive.value) return;

  const predictions = await faceDetector.detect(videoRef.value);
  const ctx = canvasRef.value.getContext('2d');

  ctx.clearRect(0, 0, canvasRef.value.width, canvasRef.value.height);
  ctx.drawImage(videoRef.value, 0, 0, canvasRef.value.width, canvasRef.value.height);

  // 绘制绿色人脸框
  predictions.forEach(item => {
    const box = item.boundingBox;
    ctx.strokeStyle = '#00FF00';
    ctx.lineWidth = 2;
    ctx.strokeRect(box.xMin, box.yMin, box.width, box.height);
  });
}
```

### 微信浏览器三大兼容坑

| 坑点     | 解决方案                                |
| ------ | ----------------------------------- |
| 权限触发限制 | `getUserMedia` 必须在用户点击事件中调用，不能自动初始化 |
| 视频全屏   | `<video>` 必须加 `playsinline`         |
| 资源未释放  | 退出页面必须停止视频流，否则相机持续占用                |

```javascript
function stopCamera() {
  clearInterval(detectionInterval);
  stream?.getTracks().forEach(track => track.stop());
  isCameraActive.value = false;
}

onUnmounted(() => stopCamera());
```

### 低端机性能优化

```javascript
function getOptimalInterval() {
  // navigator.deviceMemory < 4G 判定为低端机
  return navigator.deviceMemory < 4 ? 200 : 100;
}
```

- 动态调整分辨率：根据设备性能降低视频尺寸
- 降低检测频率：低端机 200ms，高端机 100ms
- Web Worker 分流：人脸检测放子线程，不阻塞主线程

### 完整流程

用户点击 → 申请相机权限 → `<video>` 渲染视频流 → Canvas 承载 + 实时人脸检测 → 点击拍照输出带水印图片 → 关闭组件释放资源
