# 枚举管理

亮点：
- 梳理 TypeScript enum / const enum / 对象枚举三种方式的编译差异和适用场景
- 引入 enum-plus 和 enumOf 两种增强方案，解决业务枚举信息密度低、不够内聚的问题
- enumOf（rattail）轻量 + 类型安全 + 原生国际化支持
- 可直接复制使用的成品代码

## TypeScript 原生枚举

### enum

支持数字和字符串值，编译后生成运行时对象。

```TypeScript
// 数字枚举
enum Status {
  Pending,
  Success,
  Failed
}
Status.Pending // 0
Status[Status.Pending] // 'Pending'（数字枚举支持反向映射）

// 字符串枚举
enum Status {
  Pending = 'pending',
  Success = 'success',
  Failed = 'failed'
}
Status.Pending // 'pending'（字符串枚举不支持反向映射）
```

注意：字符串枚举编译后会产生键值冲突风险（当 value 恰好和 key 重名时命名空间混乱），定义时避免 value 与 key 重名。

### const enum

编译时抹除枚举对象，调用处直接替换为字面量，零运行时开销。

```TypeScript
const enum Status {
  Pending,
  Success,
  Failed
}

Status.Pending // 编译后直接变成 0
```

注意：不支持反向映射，不适合需要运行时遍历枚举项的场景。

## 对象枚举

最灵活的方式，开发者可自由定义映射，类型使用更明确。

```TypeScript
const Status = {
  Pending: 'pending',
  Success: 'success',
  Failed: 'failed'
} as const

type ValueOf<T> = T[keyof T]
type Status = ValueOf<typeof Status> // 'pending' | 'success' | 'failed'

// UI 映射
const StatusLabels = {
  [Status.Pending]: '准备中',
  [Status.Success]: '成功',
  [Status.Failed]: '失败',
}

StatusLabels[Status.Pending] // '准备中'
```

适用场景：绝大多数 Web App 业务开发，不在意 bundle 尺寸，追求好用 + 类型安全。

## 增强枚举库

### enum-plus

增强版枚举，提供 label、items、遍历等丰富 API，完全兼容原生 enum 用法。

- [GitHub](https://github.com/shijistar/enum-plus)：原生 enum 的 drop-in 替代，支持 React/Vue 插件。

```TypeScript
import { Enum } from 'enum-plus'

const WeekEnum = Enum({
  Sunday: { value: 0, label: 'I love Sunday' },
  Monday: { value: 1, label: 'I hate Monday' },
})

WeekEnum.Sunday           // 0
WeekEnum.items[0].key     // 'Sunday'
WeekEnum.items[0].label   // 'I love Sunday'
```

注意：API 较为丰富但也偏复杂，类型约束相对宽松（如 `WeekEnum.label(2)` 不会报类型错误）。

### enumOf（rattail）

轻量 + 类型安全 + 原生国际化支持，Varlet 团队出品，集成在 [rattail](https://github.com/varletjs/rattail) 工具库中。

```TypeScript
import { enumOf } from 'rattail'

const Status = enumOf({
  Success: { value: 0, label: 'Success' },
  Warning: { value: 1, label: () => t('global.warning') }, // label 支持函数，国际化友好
})

Status.Success                      // 0
Status.label(Status.Success)        // 'Success'
Status.options()                    // [{ value: 0, label: 'Success' }, { value: 1, label: 'Warning' }]
Status.values()                     // [0, 1]
Status.labels()                     // ['Success', 'Warning']
```

支持扩展字段（如 color、icon），类型推导完整：

```TypeScript
const Status = enumOf({
  Success: { value: 1, label: 'Success', color: 'green' },
  Warning: { value: 2, label: 'Warning', color: 'orange' },
})

Status.option(Status.Success).color // 'green'
```

配合 `rekey` 调整 options 数据结构（业务开发常见需求）：

```TypeScript
import { rekey } from 'rattail'

Status.options().map(option => rekey(option, { value: 'key' }))
// [{ key: 1, label: 'Success', color: 'green' }, { key: 2, label: 'Warning', color: 'orange' }]
```

## 选型建议

| 方案 | 类型安全 | 运行时开销 | UI 映射 | 国际化 | 推荐场景 |
|------|---------|-----------|---------|--------|---------|
| enum | 一般 | 有 | 手动 | 手动 | 简单状态标记 |
| const enum | 一般 | 无 | 不支持 | 不支持 | 对 bundle 敏感的库 |
| 对象枚举 + as const | 强 | 有 | 手动 | 手动 | 大部分 Web App 业务 |
| enum-plus | 一般 | 有 | 内置 | 手动 | 需要丰富枚举 API |
| enumOf（rattail） | 强 | 有 | 内置 | 内置 | 重视类型安全 + 国际化 |
