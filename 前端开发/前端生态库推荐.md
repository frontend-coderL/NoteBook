# 前端生态库推荐

## 工程与构建

### 统一工具链

- [Utoo](https://github.com/utooland/utoo) ⭐：统一前端工具链，尝试把包管理、开发调试、构建打包与浏览器内开发环境收敛到同一套命令和配置中，适合希望减少工具链碎片化的团队与项目。
  - 主要能力：`utoo`/`ut` 负责依赖安装，`@utoo/pack` 基于 Turbopack + SWC 提供开发与构建能力，`@utoo/web` 支持在浏览器中直接完成项目开发、安装依赖与预览。
  - 适用场景：想统一 npm / pnpm、Vite / Webpack 使用体验的新项目；希望平滑提速旧 Webpack 项目；需要在线 Demo、教学演示或浏览器内开发环境的平台型场景。
  - 注意：这类一体化工具链适合减少配置心智负担，但是否成熟到生产默认选型，仍建议结合团队现有 Webpack / Vite 资产、插件兼容性与迁移成本评估。

### Monorepo

- [monorepo.tools](https://monorepo.tools/) ⭐：Monorepo 技术选型导航站，系统整理主流 Monorepo 工具链（如 Turborepo、Nx、Rush、Lerna 等），帮助快速对比与决策。
  - 适用场景：多包项目（packages / apps）、前端工程架构设计、微前端 / 组件库 / SDK 管理
- pnpm workspace
- Turborepo
- Nx

### 构建工具与打包器

- Vite（当前主流）
- Turbopack（Next.js力推）
- [Rsbuild](https://github.com/web-infra-dev/rsbuild)：一个由 Rspack 驱动的高性能构建工具。它提供了精心设计的默认配置，让你无需任何配置即可开始项目，同时完全利用了 Rspack 的卓越性能。
- [tsdown](https://github.com/rolldown/tsdown) ⭐：由 Rolldown 驱动的库捆绑器，为 TypeScript 和 JavaScript 库提供无缝且高效的打包方式。
  - 主要特点：
    - 简化的配置：`tsdown` 提供了针对库开发的合理默认配置，减少了复杂配置的需求。
    - 面向库的特性：与作为通用打包器的 Rolldown 不同，`tsdown` 专为构建库而优化。

### Vite / Webpack 插件

- [vite-plugin-qrcode](https://github.com/svitejs/vite-plugin-qrcode)：服务器启动时显示二维码，方便移动设备访问本地开发环境。
- [plugin-web-update-notification](https://github.com/GreatAuk/plugin-web-update-notification)：检测网页更新并通知用户刷新页面，支持 Vite、Umijs 和 Webpack，使用版本号（如 git commit hash）进行比较。
- [vite-plugin-validate-env](https://github.com/Julien-R44/vite-plugin-validate-env)：Vite 插件用于验证环境变量，在构建或开发时验证环境变量，确保配置正确，支持内置验证器和标准模式（如 Zod）。
- [vite-plugin-mock-dev-server](https://github.com/pengzhanbo/vite-plugin-mock-dev-server)：为 Vite 提供 API 模拟开发服务器，支持多种文件类型和热更新。
- [unplugin-auto-import](https://github.com/unplugin/unplugin-auto-import) ⭐：自动导入 Vue、Vue Router、Pinia、VueUse 等常用 API，减少样板 `import`，非常适合组合式 API 项目。
  - 适用场景：Vue 3 + TypeScript 项目、组合式函数较多的中大型项目、统一自动导入规范。
- [unplugin-vue-components](https://github.com/unplugin/unplugin-vue-components) ⭐：自动按需导入组件，常用于 Element Plus、Ant Design Vue、Naive UI 等组件库，也适合本地组件目录自动注册。
  - 注意：适合减少手写组件注册代码；如果项目组件来源复杂，建议配合约定式目录一起使用。
- [vite-plugin-compression](https://github.com/vbenjs/vite-plugin-compression)：Vite 构建时自动生成 gzip / brotli 压缩资源，用于提升线上静态资源传输效率。
  - 适用场景：后台系统、内容站点、静态资源较多的生产环境部署。

### 框架迁移

- [vue-ai-migrator](https://github.com/TylerDurden75/vue-ai-migrator)：最全面的 Vue 2 → Vue 3 迁移工具，支持基于 AST 的转换和 AI 集成。自动转换为 Composition API、脚本设置、路由器 4 和 Pinia。

## JS 工具库

- [es-toolkit](https://github.com/toss/es-toolkit)：一个现代 JavaScript 工具库，速度快 2-3 倍，体积小了 97%，是 lodash 的重大升级。
- [radashi](https://github.com/radashi-org/radashi)：Radash官方归档后的社区续命版，性能比Lodash快3-7倍，体积减少75%。
  - 采用ES2020全新算法，零`any`，错误优先风格，类型体验拉满。
  - 维护活跃， nightly 发版，RFC公开投票，适配最新前端生态。
- [lodash-es](https://github.com/lodash/lodash)：Lodash 的 ES Module 版本，适合按需引入常用工具函数，如防抖、深拷贝、数组处理和对象操作。
  - 注意：优先按函数维度引入；如果只是少量简单工具函数，也可以先评估是否值得引入整个依赖。
- [decimal.js](https://github.com/MikeMcl/decimal.js) ⭐：高精度数字计算库，解决 JavaScript 原生浮点数精度问题，支持任意精度运算与大数字处理。
  - 注意：金额计算强烈推荐统一封装金额工具层，避免业务代码直接混用原生 Number。
- [dayjs](https://github.com/iamkun/dayjs) ⭐：轻量级时间处理库，API 风格接近 Moment.js，但体积更小，适合日期格式化、时间差计算和常见时间逻辑处理。
- [qs](https://github.com/ljharb/qs)：查询参数序列化与解析工具，常用于 GET 参数拼接、表单提交和后端约定的复杂参数结构处理。
  - 适用场景：与 Axios 配合提交 `application/x-www-form-urlencoded` 数据，或处理嵌套对象参数。
- [validator.js](https://github.com/validatorjs/validator.js)：通用字符串校验库，覆盖邮箱、手机号、URL、IP、长度、正则规则等高频验证场景。
  - 适用场景：表单验证、登录注册、URL 检查、手机号和邮箱格式校验。
  - 注意：适合做基础规则校验；复杂业务表单建议结合 `zod`、`yup` 或 `vee-validate`。
- [crypto-js](https://github.com/brix/crypto-js)：常用前端加密与摘要算法库，支持 MD5、SHA256、AES、HMAC 等。
  - 注意：前端加密主要用于传输和展示层安全增强，真正安全仍依赖 HTTPS、服务端签名校验和密钥管理。
- [js-cookie](https://github.com/js-cookie/js-cookie)：轻量级 Cookie 操作库，封装浏览器 Cookie 的增删改查，常用于登录态、偏好设置等简单持久化场景。
- [pinyin-match](https://github.com/xmflswood/pinyin-match)：拼音匹配，具备分词、缩写、多音字匹配能力，支持繁体版

## 应用骨架

### 国际化 (i18n)

- [vue-i18n: Vue I18n for Vue 3](https://github.com/intlify/vue-i18n) ⭐
- [unplugin-vue-i18n](https://github.com/intlify/bundle-tools/tree/main/packages/unplugin-vue-i18n)

### 路由

- [Vue Router](https://github.com/vuejs/router) ⭐：Vue 3 官方路由方案，支持嵌套路由、动态路由、路由守卫和懒加载，是单页应用的基础设施之一。
  - 适用场景：后台管理系统、内容站点、需要权限控制和页面拆分的 Vue 应用。

### 组合式工具

- [VueUse](https://github.com/vueuse/vueuse) ⭐：Vue 生态最常用的组合式工具集，围绕浏览器能力、状态管理、事件监听、存储、时间和交互等场景提供大量现成 composables。
  - 适用场景：本地存储封装、窗口尺寸监听、防抖节流、暗黑模式、剪贴板、传感器能力等高频前端场景。

### 状态管理

- [Pinia](https://github.com/vuejs/pinia) ⭐：Vue 3 官方推荐的状态管理库，语法比 Vuex 更轻，TypeScript 体验更自然，适合作为绝大多数 Vue 项目的默认状态层。
  - 适用场景：全局用户状态、权限信息、业务缓存、组件间共享状态。
- [pinia-colada](https://github.com/posva/pinia-colada) ⭐：专注服务端状态缓存，类似 TanStack Query 的 Pinia 风格方案。
  - **适用场景**：列表缓存、请求去重、自动刷新、乐观更新。
- [pinia-plugin-persistedstate](https://github.com/prazdevs/pinia-plugin-persistedstate)：最常用的 Pinia 持久化插件，可将 store 自动同步到 localStorage / sessionStorage / cookie。
  - 适用场景：登录态、用户配置、主题模式、多页签缓存。
- [pinia-plugin-persist](https://github.com/Seb-L/pinia-plugin-persist)：轻量级持久化方案，支持自定义存储策略。
  - 适用场景：对持久化逻辑有二次封装需求的项目。
- [pinia-plugin-debounce](https://github.com/posva/pinia-plugin-debounce)：为 actions 增加防抖能力，避免高频触发请求。
  - 适用场景：搜索输入、表单自动保存、实时筛选。
- [pinia-shared-state](https://github.com/wobsoriano/pinia-shared-state)：多标签页共享 Pinia 状态，基于 BroadcastChannel / localStorage 通信。
  - 适用场景：后台管理系统多标签同步、H5 多窗口同步。
- [pinia-undo](https://github.com/wobsoriano/pinia-undo)：为 Pinia Store 添加撤销 / 重做能力，跟踪状态变化并提供历史记录。
  - 适用场景：表单编辑器、低代码页面搭建、流程配置、画布类应用、AI 对话草稿回退。
- [pinia-orm](https://github.com/CodeDredd/pinia-orm)：为 Pinia 提供 ORM 能力，支持 Model、Relation、Query。
  - 适用场景：复杂业务数据管理，如 IM、审批流、组织架构、商品系统。

### Head 与 SEO

- [unhead](https://github.com/unjs/unhead) ⭐：Unhead 是一款文档`<head>`和模板管理器，致力于提升反应式 SSR JavaScript 框架开发者的体验、SEO 和性能。

### 网络请求

- [Axios](https://github.com/axios/axios) ⭐：前端最常用的 HTTP 客户端之一，支持请求 / 响应拦截器、取消请求、超时控制和统一错误处理，适合作为项目请求层基础。
  - 适用场景：接口鉴权、统一错误处理、文件上传、请求封装。

## 业务场景组件

### 二维码 / 条形码

- [bwip-js](https://github.com/metafloor/bwip-js)：把专业级 PostScript 条形码生成器翻译成纯 JS 的库， 不依赖图片服务、不调用外部接口、不联网，在浏览器、Node.js、React、React Native、Electron 里直接生成标准条形码。
- [vue-qrcode-reader](https://github.com/gruhn/vue-qrcode-reader)：一套用于检测和解码二维码的 Vue.js 组件。

### 电子签名

- [vue3-signature-pad](https://github.com/selemondev/vue3-signature-pad)：基于 HTML5 Canvas 实现的 Vue3 签名板组件

### 打印与导出

- [Vue-Print-Designer](https://github.com/0ldFive/Vue-Print-Designer)：一款可视化打印设计器，面向业务表单、标签、票据、快递单等场景，支持模板化、变量化，并提供静默打印与云打印能力，同时兼容多种导出/打印方式。

### 表单与表格

- [vxe-table](https://github.com/x-extends/vxe-table) ⭐：Vue 生态高性能表格方案，支持虚拟滚动、树形表格、合并单元格、导入导出等复杂能力，适合中后台重表格场景。
  - 适用场景：大数据量表格、财务/报表系统、复杂可编辑表格。
- [vee-validate](https://github.com/logaretm/vee-validate)：Vue 生态成熟的表单验证方案，支持组合式 API、自定义校验规则以及与 `yup` 等 Schema 校验库配合使用。
  - 适用场景：复杂表单、动态表单、需要统一错误提示和校验流程的业务页面。

### 日历与时间

- [Schedule-X](https://github.com/schedule-x/schedule-x)：现代化的 JavaScript 事件日历，FullCalendar / react-big-calendar 的开源免费替代。
  - 多框架支持：一套 core + 五大框架适配器（React / Angular / Vue / Svelte / Preact），同一 API 跨框架。
  - 开箱即用：日 / 周 / 月网格 / 月议程 / 列表视图内置，拖拽 / 缩放 / 暗色模式 / 国际化无需额外配置。
  - 时区友好：v3 底层切到 Temporal API，跨时区事件、全天事件（PlainDate）直接可用。
  - 计划中：农历（非格里高利历）支持——示例代码已写好，`locale: 'zh-CN' + calendarSystem: 'chinese'` 即可。
  - 商用：MIT 协议。FullCalendar 风格的资源视图 / 排班等企业级能力需 Premium。

## 内容编辑器

### 富文本编辑

- [Tiptap Editor](https://tiptap.dev/)：基于 ProseMirror 的 headless 富文本编辑器框架，支持扩展节点、mark、命令、快捷键、React / Vue 集成，也有协同、评论、AI、文件转换等商业能力。
- [ProseMirror](https://prosemirror.net/)：Web 富文本编辑器底层工具包，提供文档模型、schema、transaction、selection、plugin、collaboration 等核心能力。
- [TinyMCE](https://www.tiny.cloud/tinymce)：成熟的 WYSIWYG（所见即所得）HTML 编辑器，支持插件、表格、图片、粘贴、React / Vue / Angular 集成、云服务和商业支持。
- [wangEditor](https://www.wangeditor.com/)：国内常见开源 Web 富文本编辑器，开箱即用，配置简单，支持 JS、Vue、React。
- [novel](https://github.com/steven-tey/novel)：一个开源的 Notion 风格所见即所得编辑器，带有 AI 驱动的自动补全功能。

### 文档预览（PDF / Office）

- [jit-viewer-sdk](https://github.com/jitOffice/jit-viewer-sdk)：一款强大的office文档预览sdk，支持word，pdf，markdown，ppt，excel等文件的预览
- [vue-office](https://github.com/501351981/vue-office)：支持word(.docx)、excel(.xlsx,.xls)、pdf等各类型office文件预览的vue组件集合，提供一站式office文件预览方案，支持vue2和3，也支持React等非Vue框架。

## 数据可视化与动效

### 图表库

- [Apache ECharts](https://github.com/apache/echarts) ⭐：前端通用图表库，覆盖折线图、柱状图、饼图、地图、仪表盘等常见可视化需求，生态成熟、资料丰富。
- ECharts/AntV G2：
  - 基于 `Canvas 2D` 或 `SVG`。渲染逻辑跑在 CPU，每次重绘都要跑完整流程。当图表实例增多或数据量增大时，CPU 很快成为瓶颈。
- [vue-echarts](https://github.com/ecomfe/vue-echarts)：Apache ECharts™ 的 Vue.js 组件。
- [ChartGPU](https://github.com/ChartGPU/ChartGPU)：美丽、开源、基于 WebGPU 的图表库
  - GPU 并行计算 + 绘制。数据越大，GPU 的并行优势越明显，帧率越稳。

### 大屏与缩放适配

- [autofit.js](https://github.com/Auto-Plugin/autofit.js)：无框架依赖的通用缩放工具，通过计算容器与设计稿的比例，对整个页面进行缩放处理，核心逻辑是 `transform: scale(ratio)` 的全局应用。
- [vfit.js](https://github.com/v-plugin/vfit) ⭐：专为 Vue 3 设计的轻量方案，不仅提供全局缩放，更通过组件化思想解决**精细定位**问题，是"缩放+定位"的一体化方案。

### 渲染与动效

- [animate.css](https://github.com/animate-css/animate.css)：开箱即用的 CSS 动画库，适合快速补充入场、强调、退出等基础动画效果。
  - 注意：适合营销页、运营页和轻交互动效；后台系统中建议克制使用，避免动画噪音过大。
- [@vueuse/motion](https://github.com/vueuse/motion) ⭐：面向 Vue 的声明式动效工具，适合基于组合式 API 做滚动触发、元素过渡和交互反馈动画。
  - 适用场景：卡片入场、滚动 reveal、微交互反馈、展示型页面动效。
- [nprogress](https://github.com/rstacruz/nprogress)：顶部细进度条组件，常用于路由切换或异步请求加载反馈，成本低但很能提升体感。
- [number-flow](https://github.com/barvian/number-flow)：高质量数字滚动动画组件，在数字变化时提供类似 Apple 风格的平滑过渡效果，适用于计数器、金额、百分比、指标面板等场景。
  - 注意：适合展示层数字动画，不建议承载复杂业务逻辑，推荐与 computed、VueUse 状态流结合使用。
- [pretext](https://github.com/chenglou/pretext)：快速、准确且全面的文本测量与布局引擎

## 监控与可观测

### 产品分析

- [PostHog](https://github.com/PostHog/posthog)：PostHog 是一个一体化的开源平台，用于打造成功的产品
  - 把产品分析、录屏回放（Session Recording）、功能开关（Feature Flags）和 A/B 测试全部整合在了一起。它的目标是：让你看清用户操作的每一个细节，并根据数据实时通过代码控制产品的走向。

### 前端监控

- [web-tracing](https://github.com/M-cheng-web/web-tracing)：为前端项目提供【 埋点、行为、性能、异常、请求、资源、路由、曝光、录屏 】监控手段
  - 轻量无依赖：gzip 压缩后不足 15KB，无第三方强依赖，不阻塞主线程，适配低性能设备。
  - 多技术栈适配：原生 JS、Vue2/3、React 一套 SDK 覆盖。
  - 录屏基于 rrweb（异常时自动录制关键流程），用户标识基于 fingerprintjs。
  - 适合：需要快速搭建全链路监控的中小团队，或想给 Vue/React 项目加埋点又不想自研的个人开发者。

### 录屏回放

- [rrweb](https://github.com/rrweb-io/rrweb)：开源的前端录制回放工具，核心定位是 “轻量级、高保真、可扩展的 Web 页面录制与回放解决方案”。

## 跨端

- [Electron](https://github.com/electron/electron)：用 JavaScript、HTML 和 CSS 构建跨平台桌面应用
  - 当前最流行的桌面端方案
  - 特点：内置 Chromium + Node.js、可以直接用 React / Vue / Vite、生态成熟，插件多
  - 缺点：体积大、内存占用高
- [Tauri](https://github.com/tauri-apps/tauri)：构建更小、更快、更安全的桌面和移动应用，并配备网页前端。
  - Electron 的“轻量替代”
  - 特点：前端：HTML/CSS/JS（React/Vue）；后端：Rust；使用系统 WebView
  - 优点：体积小、性能更好、更安全（权限控制严格）
  - 适合：追求性能 + 体积的小工具、客户端
- [Flutter](https://github.com/flutter/flutter)：Google 的跨平台 UI 框架
  - 特点：用 Dart 写、自带渲染引擎（不是 Web），性能接近原生、UI 一致性强
  - 适合：对性能和 UI 要求高的应用
- [PerryTS/perry](https://github.com/PerryTS/perry)：一个用 Rust 编写的本地 TypeScript 编译器。
  - 直接把你的 TypeScript 编译成原生可执行文件——没有 Node.js，没有 Electron，也没有浏览器引擎。只是快速、小的二进制，能跑到任何地方。
